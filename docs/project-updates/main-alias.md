# Main Alias Branch

This branch is a general-purpose development workspace created from the repository's `main` branch.

## Working agreement

- Keep `main` as the stable integration branch.
- Make ongoing feature and maintenance changes on `feature/main-alias`.
- Keep this branch aligned with `main` by syncing it when needed.
- Submit pull requests from this branch to `main` when changes are ready.
- Run the repository's required CI checks before merging.

This note documents the branch workflow only; it does not change application behavior, database schemas, or deployment settings.
